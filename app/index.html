🔄 Live Multi-Device Sync (optional)

🚫 Disabled in demo. This is a public demo with synthetic data; this integration is switched off in code and cannot connect to any account.
💡 Turn this on if more than one person/device needs to see the same live sales and stock data at once (e.g. two billing counters, or owner checking from home while staff bills in the shop). Without this, each device keeps its own local copy, synced only through nightly backups — which is simpler and works fine for a single till. See the guide for exact one-time setup steps (free Firebase project).

📁 Excel File (Auto-Save Backend)

💡 If this computer breaks or is lost, this Excel file is your only local copy. For free protection: (1) when connecting below, choose a location inside your Google Drive or OneDrive desktop-sync folder if you have one installed — it will then back up to the cloud automatically at no cost, or (2) turn on the Telegram backup further down, which sends a copy of this file to your phone/group every night for free.

☁️ Google Drive Backup (automatic)

🚫 Disabled in demo. This is a public demo with synthetic data; this integration is switched off in code and cannot connect to any account.

On top of the local Excel file, this can push a copy straight to your own Google Drive automatically — no desktop sync app required, works from any device. One-time setup: create a free Google OAuth Client ID for this app (see the README for the exact steps) and paste it below.

🤖 Telegram Daily Summary & Free Backup

🚫 Disabled in demo. This is a public demo with synthetic data; this integration is switched off in code and cannot connect to any account.

Get an automatic business summary sent to a Telegram chat or group at 2:00 PM and 9:00 PM — as long as this app is open in a browser tab at that time. The 9 PM message also carries your Excel file as an attachment, so a copy of your data lands somewhere other than the shop's computer every night, for free. Create a free bot via @BotFather on Telegram to get a token, then add your bot to your group and get the chat ID (e.g. via @userinfobot or @getidsbot).

Each one must be a Chat ID, not a phone number — Telegram bots can't message a phone number directly. Easiest for several people: add everyone + the bot to one Telegram group and use that group's Chat ID (see README). To message people separately instead, each person must first send the bot any message, then you look up their personal Chat ID via @userinfobot and add it here.
